## Type pairing
- Display: Archivo at 75% width, bold (--font-display), diagram titles, box titles and chart labels
- Body: Source Serif 4 (--font-body), the sentences inside the diagrams and the chart's notes
- Why: a narrow sans over a book serif (structure and width), bold over regular (weight). The terminal picture uses JetBrains Mono because it shows real command output.
